### 2.4 검증 중 발견·수정된 결함

| # | 결함 | 원인 | 수정 |
|---|---|---|---|
| D1 | 화면 전환 영구 멈춤 (백그라운드 탭) | `AnimatePresence mode="wait"`의 exit가 rAF 스로틀링으로 미완료 | 전환 모드 변경 — exit 완료에 비의존 |
| D2 | 원본 사진 삭제 실패 (Windows) | sharp(libvips) 연산 캐시가 파일 핸들 유지 | `sharp.cache(false)` + 삭제 재시도 + 고아 파일 스위퍼 3중 방어 |
| D3 | CORE1 드래그 단일 입력 위험 | 터치 환경별 드래그 인식 편차 | 모달 내 REPICK 버튼 병행 (스와이프+버튼의 CORE4 패턴과 통일) |
| D4 | dev 서버 무한 재시작 | Dropbox 동기화가 node_modules 파일 변경 유발 | watch ignore 설정 |
| D5 | better-sqlite3 네이티브 빌드 실패 | VS 툴체인 부재 | Node 내장 `node:sqlite`로 교체 (의존성 제거) |
| D6 | **화면 누적 — 이전 화면이 언마운트되지 않음** (게임 3개가 DOM에 동시 존재, 이전 화면의 완료 토스트가 다음 화면에 표시됨) | `AnimatePresence`의 exit 애니메이션이 완료되지 않아 언마운트가 지연/누락 | AnimatePresence 제거, `key` 변경으로 즉시 교체 + 진입 애니메이션만 유지 (D1의 근본 원인이기도 함) |

> D6는 디자인 반영 중 스크린샷 검증으로 발견됐다. 화면이 쌓이면 이전 화면의 타이머(CORE3의 10초 제한 등)와
> 상태가 계속 살아 있어 오작동·메모리 누수로 이어지므로, 장시간 무인 운영되는 키오스크에서는 치명적이다.

| D7 | **CORE3 시간 초과 시 진행 불가** — 10초가 지나면 게임이 종료되지 않고 화면이 멈춤 | `setPicked(cur => { finish(cur); … })` — setState updater 내부에서 상태 업데이트를 호출해 React 18에서 부작용이 유실됨 | 최신 선택을 `pickedRef`로 추적, 타이머는 정지만 담당. 시간 초과 시에도 '다음' 버튼이 활성화되어 선택분만으로 채점 진행 |

> D7은 CORE3 디자인 반영 중 시간 초과 경로를 직접 재현해 발견했다. 3장을 모두 고른 정상 경로만 테스트되어
> 그동안 드러나지 않았다. 방문객이 10초 안에 3장을 못 고르면 체험이 그 자리에서 멈추는 치명적 결함이었다.

| D8 | **CORE1 카드 드래그 불가** — 마우스로 제품 카드를 REPICK 존에 끌 수 없음 | 제품 일러스트를 SVG→실제 이미지로 교체하면서 브라우저 기본 이미지 드래그(`-webkit-user-drag: auto`)가 포인터 드래그를 가로챔 | 전역 CSS로 이미지 드래그 차단 + `draggable={false}` + 드롭 판정에 이동량(offsetY) 조건 병행 |

> D8은 사용자 제보로 확인했다. JS 이벤트 시뮬레이션으로는 재현되지 않아 **실제 마우스 드래그**로 검증해야 했다
> (framer-motion의 포인터 캡처는 합성 이벤트로 정확히 재현되지 않음). 대안 입력(모달 REPICK 버튼)이 있어
> 체험이 막히지는 않았으나, 시안이 의도한 주 조작 방식이 동작하지 않는 상태였다.

## 5. 2차(현장 배포) 단계 권고사항

1. **Android 쉘**: Kotlin WebView + Lock Task Mode, 카메라 권한 자동 승인, 부팅 시 자동 실행, 하트비트(구현된 `/api/admin/devices/:id/heartbeat` 활용)
2. **실 AI 이미지**: `GenAiGenerator` 어댑터에 이미지 생성 API 연동 — 폴백 경로는 이미 검증 완료이므로 위험 낮음
3. **인프라 전환**: SQLite→PostgreSQL, 인메모리 큐→Redis, 로컬 파일→S3+CDN (인터페이스 분리로 교체 지점 명확)
4. **QR 공인 도메인**: `PUBLIC_BASE_URL`을 `https://result.aepick.com`으로, HTTPS 필수 (Web Share·다운로드 UX)
5. **현장 리허설**: 실제 태블릿에서 조명·각도별 촬영 품질, 게임별 소요시간 실측(5분 목표 검증), 베트남어 감수본 적용

## 6. 결론

프로토타입의 **전 구성요소가 기획 스펙대로 동작함을 확인**했다.
핵심 안전장치(AI 폴백, 개인정보 즉시 삭제, 세션 타임아웃, 오프라인 내성)가 모두 검증되었고,
발견된 결함 5건은 전량 수정 완료. 실기기 카메라 검증과 현지어 감수를 전제로
현장 배포 단계(2차) 진행이 가능한 상태다.
