# AEPICK BEAUTY DNA v2 — 디자이너 가이드

> 이미지를 교체하는 방법과, 어떤 파일이 어느 화면에 쓰이는지 정리한 문서입니다.
> **개발자 도움 없이** 이미지만 바꿔서 반영할 수 있도록 만들었습니다.

---

## 0. 3줄 요약

1. 이미지는 전부 `apps/kiosk/public/assets/ui/` 폴더에 있습니다.
2. **파일명을 그대로 유지한 채 덮어쓰면** 코드 수정 없이 바뀝니다.
3. 브랜드 로고와 제품 사진은 파일이 아니라 **어드민 화면(`/admin/catalog`)에서 경로를 입력**합니다.

---

## 1. 작업 전에 알아둘 것

### 화면 비율

키오스크는 **안드로이드 태블릿 세로 모드** 기준입니다.
시안은 **1200 × 1800 (2:3)** 로 잡으면 실제 화면과 가장 가깝습니다.

### 파일 형식

| 종류 | 형식 | 이유 |
|---|---|---|
| 아이콘 · 장식 · 제품컷 | **PNG (투명 배경)** | 배경 위에 얹히므로 투명이 필수 |
| 전면 이미지 (브릿지 · 종료) | **JPG** | 화면을 꽉 채워 투명이 필요 없고 용량이 작음 |

### 용량

한 장당 **250KB 이하**를 권합니다.
현재 가장 큰 파일이 `photocards.png` 820KB인데, 태블릿에서 첫 로딩이 느려지는 원인입니다.

### 해상도

표시 크기의 **2배**로 만들면 충분합니다(고해상도 대응).
예: 화면에서 60px로 보이는 아이콘 → 120×120으로 제작.

## 2. 교체 방법

```
1. apps/kiosk/public/assets/ui/  폴더를 엽니다
2. 바꾸고 싶은 파일과 "똑같은 이름"으로 새 이미지를 덮어씁니다
3. 개발자에게 "빌드해 주세요" 라고 알립니다  (또는 START-DEMO.bat 재실행)
```

> **파일명을 바꾸면 이미지가 사라집니다.** 코드가 이름으로 찾기 때문입니다.
> 이름을 꼭 바꿔야 한다면 개발자에게 알려주세요.

확장자도 유지해야 합니다. `bridge-repick.jpg`를 PNG로 바꾸려면 코드 수정이 필요합니다.

## 4. 브랜드 로고와 제품 사진 — 어드민에서 넣습니다

이 두 가지는 파일 폴더가 아니라 **관리 화면에서 경로를 입력**합니다.
운영 중에 브랜드가 바뀌어도 개발자 없이 교체할 수 있게 하기 위함입니다.

### 절차

```
1. 이미지를 apps/kiosk/public/assets/brands/ 폴더에 넣습니다
   (폴더가 없으면 새로 만드세요)

2. 브라우저에서  http://<주소>/admin/catalog  를 엽니다
   → 관리자 키를 물어보면 운영자에게 받으세요

3. 브랜드 줄의 "로고 이미지 경로" 칸에 입력합니다
      /assets/brands/purelab-logo.png
   제품 사진도 같은 방식입니다

4. [저장] 을 누르면 즉시 반영됩니다 (빌드 불필요)
```

### 권장 규격

| 항목 | 크기 | 형식 | 비고 |
|---|---|---|---|
| 브랜드 로고 | 200×200 | PNG 투명 | 정사각형. 둥근 사각형으로 잘려 보임 |
| 제품 사진 | 400×400 | PNG 또는 JPG | 정사각형. 투표 화면에서 작게 표시 |

로고를 넣지 않으면 **이모지가 대신 표시**됩니다. 급할 때는 이모지만으로도 운영 가능합니다.

## 5. 지금 상태에서 꼭 알아야 할 두 가지

### (1) 브릿지·종료 화면이 한국어 전용입니다

7장의 이미지(`bridge-*.jpg` 6장 + `end-final.jpg`)는 **글자가 그림 안에 박혀** 있고, 현재 **한국어만** 있습니다.

하노이 팝업은 베트남 고객이 주 대상이므로 **베트남어 버전이 필요**합니다.

해결 방법은 두 가지입니다.

| 방법 | 작업량 | 결과 |
|---|---|---|
| **A. 언어별 이미지 제작** | 7장 × 3개 언어 = **21장** | 지금 구조 그대로. 개발 작업 소량 필요 |
| **B. 글자를 빼고 배경만** | 7장 | 글자는 코드가 얹음. 번역만 바꾸면 되고 유지보수가 쉬움 |

**B를 권합니다.** 문구 수정 때마다 디자이너를 거치지 않아도 되고, 언어가 늘어도 이미지를 다시 만들 필요가 없습니다.
다만 글자 위치·크기를 개발자와 함께 정해야 합니다.

### (2) 대기화면 3단계 아이콘이 옛 기획 그림입니다

3-2에 적은 대로, `step-photo.png`(카메라)와 `step-ai.png`(AI)는 **v2에 없는 기능**을 나타냅니다.
**QR 스캔**과 **브랜드 추천**으로 교체가 필요합니다.
