# AEPICK BEAUTY DNA — 해외 시연 가이드

> ⚠️ **이 문서는 v1(사진 촬영 + AI 이미지 생성) 기준입니다.**
> v2는 사진·AI를 제외하고 app 계정 페어링과 제품 투표를 도입했습니다.
> 현재 구현 기준 문서는 [BE 인계문서](07_BE_인계문서.md)와 [디자이너 가이드](06_디자이너_가이드.md)입니다.
> 이 문서는 채점 로직·페르소나 정의 등 **v2에서도 유효한 부분**을 참고하는 용도로 남겨 둡니다.

> 구성: **노트북(서버) + 태블릿(키오스크) + 휴대폰(QR 스캔)** · 현장 Wi-Fi 사용

---

## 0. 가장 쉬운 실행 — 더블클릭

프로젝트 폴더의 **`START-DEMO.bat` 파일을 더블클릭**하면 끝이다.
경로·명령어를 몰라도 되고, 폴더 위치가 바뀌어도 자동으로 찾는다.

| 파일 | 하는 일 |
|---|---|
| **`START-DEMO.bat`** | Node 확인 → (최초 1회) 패키지 설치 → 빌드 → **HTTPS 서버 실행** |
| **`START-TUNNEL.bat`** | 위와 같되 **공개 주소(터널)로 실행** — 8번 참고 |
| **`SEED-DATA.bat`** | 대기화면 통계 채우기(1) / 지우기(2) |

- 창에 표시되는 **`KIOSK (TABLET)` 주소**를 태블릿 브라우저에 입력한다
- 종료: 그 창에서 `Ctrl + C` 또는 창 닫기
- 창을 닫으면 서버도 꺼지므로 **시연 중에는 창을 그대로 둔다**

> 터미널에 익숙하다면 아래 1번의 `npm run demo`와 동일하다.

## 1. 출발 전 준비 (사무실에서 반드시 1회 리허설)

```bash
npm install          # 최초 1회
npm run demo         # 빌드 + HTTPS 서버 기동
```

기동하면 콘솔에 접속 주소가 표시된다.

```
  키오스크(이 PC)   https://localhost:8787/
  키오스크(태블릿)  https://10.100.180.111:8787/     ← 이 주소를 태블릿에 입력
  운영자 대시보드   https://localhost:8787/admin
```

체크리스트

- [ ] 노트북 브라우저에서 `https://localhost:8787/` → 전체 여정 1회 완주
- [ ] 태블릿에서 위 LAN 주소 접속 → **인증서 경고 [고급] → [계속]** 1회 수락
- [ ] 태블릿에서 **카메라 권한 허용** → 얼굴 촬영 동작 확인
- [ ] 휴대폰으로 QR 스캔 → 결과 페이지 열림 + 이미지 다운로드 확인
- [ ] `npm run demo:seed` 로 대기화면 통계 채우기
- [ ] AI 이미지 연동 시: 아래 2번 설정 후 실제 생성 1회 확인
- [ ] **노트북 절전/화면잠금 해제**, 태블릿 자동잠금 해제
- [ ] **Dropbox·OneDrive 동기화 일시정지** (파일 잠금으로 빌드·이미지 저장이 실패할 수 있음)

## 2. AI 이미지 생성 (Gemini) 설정

```bash
# Windows PowerShell
$env:AI_PROVIDER="gemini"; $env:GEMINI_API_KEY="<발급받은 키>"; npm run demo

# macOS / Linux
AI_PROVIDER=gemini GEMINI_API_KEY=<발급받은 키> npm run demo
```

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `AI_PROVIDER` | `template` | `gemini` 로 바꾸면 생성형 AI 사용 |
| `GEMINI_API_KEY` | — | 없으면 자동으로 템플릿 합성 |
| `GEMINI_IMAGE_MODEL` | `gemini-2.5-flash-image` | 모델 교체용 |

> **안전장치**: 키 오류·타임아웃(20초)·네트워크 장애가 나면 자동으로 템플릿 합성으로 넘어가
> 체험이 중단되지 않는다. 검증 완료된 동작이므로 시연 중 API가 죽어도 화면은 정상 진행된다.

## 3. 현장 세팅 순서 (10분)

1. 노트북·태블릿을 **같은 Wi-Fi**에 연결
2. 노트북에서 `npm run demo` 실행 → 콘솔의 **태블릿용 주소** 확인
3. `npm run demo:seed` 실행 (다른 터미널) — 대기화면 통계 채우기
4. 태블릿 브라우저에서 주소 입력 → 인증서 경고 수락 → **전체화면 모드**
   - Android Chrome: ⋮ → 홈 화면에 추가 → 앱처럼 실행
   - iPad Safari: 공유 → 홈 화면에 추가
5. 대기화면이 보이면 준비 완료

> **IP가 바뀌면**(Wi-Fi 재접속 등) 서버를 재시작하고 태블릿 주소를 다시 입력한다.

## 4. 시연 시나리오 (약 5분)

| 순서 | 화면 | 말할 포인트 |
|---|---|---|
| 1 | 대기화면 | "오늘 참여자 N명, 가장 많이 나온 DNA는 Trend Muse" — 실시간 집계 |
| 2 | 언어 선택 | 베트남어 기본 · 3개 언어 |
| 3 | 동의 | 사진/저장/분석 동의 **분리** — 개인정보 대응 |
| 4 | 촬영 | 얼굴 가이드·품질 검사 (시간 없으면 아바타 모드로 건너뛰기) |
| 5 | 6게임 | 각 30초. **CORE1 드래그**, **CORE3 10초 타이머**가 시연 임팩트가 큼 |
| 5-1 | 브랜드 메시지 | 게임마다 2초씩 자동 노출 — "AEPICK이 무엇을 기준으로 고르는가"를 전달하는 구간. 마지막 게임 뒤에는 마무리 화면이 한 번 더 나옴 |
| 6 | 분석 | 다크 연출 + 진행률 — AI 대기 시간을 콘텐츠로 전환 |
| 7 | DNA 결과 | 페르소나 + 6축 레이더 + "참여자 중 N%" |
| 8 | AI 이미지 | 본인 얼굴 기반 결과물 |
| 9 | QR | **휴대폰으로 직접 스캔** → 다운로드·브랜드 추천까지 보여주기 |
| 10 | 대시보드 | 별도 화면에서 `/admin` — 완료율·QR 스캔율·DNA 분포 |

**빠른 시연(2분)**: 동의에서 "사진 없이 아바타" 선택 → 게임은 CORE1·CORE3만 보여주고
나머지는 빠르게 진행 → 결과·QR 집중

## 5. 현장 트러블슈팅

| 증상 | 원인 | 조치 |
|---|---|---|
| 태블릿에서 **카메라가 안 켜짐** | HTTP로 접속함 | 주소가 `https://` 인지 확인. `npm run demo`는 항상 HTTPS |
| 인증서 경고가 계속 뜸 | 자체 서명 인증서 | [고급] → [계속] 1회 수락. IP가 바뀌면 다시 |
| 태블릿에서 **접속 자체가 안 됨** | 다른 Wi-Fi / 방화벽 | 같은 네트워크 확인 → Windows 방화벽에서 Node 허용 → 그래도 안 되면 **8번 터널** |
| QR을 찍었는데 안 열림 | 폰이 다른 네트워크 | 폰을 같은 Wi-Fi에 연결 → 또는 **8번 터널**(LTE로도 열림) |
| 현장 Wi-Fi가 기기 간 통신 차단 | AP 격리(게스트망) | **8번 터널**로 우회 |
| 폰트가 깨져 보임 | (해결됨) 폰트는 로컬 번들 | 캐시 삭제 후 새로고침 |
| AI 이미지가 안 나옴 | API 키/네트워크 | 자동으로 템플릿 결과가 나옴 — **정상 동작** |
| 화면이 멈춘 것 같음 | 무입력 타임아웃 대기 | 화면 탭 또는 경고창의 [처음으로 돌아가기] |
| 세션을 강제로 초기화 | — | 화면 **좌상단 5회 연속 탭** → 확인 |

## 6. 시연 후 정리

```bash
npm run demo:reset     # 시드 데이터 삭제
```

- 방문객 사진은 이미지 생성 직후 자동 삭제된다(정책 구현됨)
- 결과 이미지는 48시간 후 자동 삭제. 즉시 지우려면 `server/data/results/` 폴더 삭제
- 시연 데이터를 통째로 초기화하려면 `server/data/aepick.sqlite` 삭제 후 재기동

## 6-1. 시연 노트북으로 옮기는 방법

**권장: Dropbox 동기화보다 폴더 복사(USB 등)**

`node_modules`는 파일이 수만 개라 Dropbox 동기화가 매우 느리고, 동기화 중 파일이 잠겨
빌드가 실패한다. 아래처럼 옮기는 편이 안전하다.

1. **복사할 것**: `apps/`, `server/src/`, `packages/`, `tools/`, `docs/`,
   `START-DEMO.bat`, `SEED-DATA.bat`, `package.json`, `package-lock.json`, `tsconfig.base.json`
2. **빼도 되는 것**: `node_modules/`, `apps/kiosk/dist/`, `server/data/`
3. 시연 노트북에서 **Node.js LTS(22 이상) 설치** → `START-DEMO.bat` 더블클릭
   (최초 실행 시 자동으로 `npm install` 진행 — **인터넷 필요, 3~5분**)
4. **한국에서 이 과정을 끝내고 전체 리허설을 1회 완료**할 것

> Dropbox 폴더에서 그대로 실행해야 한다면, 최소한 **시연 중에는 Dropbox 동기화를 일시정지**한다.

### Claude Code로 실행하는 방식은?

시연 노트북에 Claude Code를 설치해 "실행해줘"라고 지시하는 방법도 가능하지만,
**시연 실행 수단으로는 권장하지 않는다.**

- Claude Code는 **인터넷이 끊기면 동작하지 않는다** → 현장 네트워크 장애 시 시연 자체가 불가
- 명령 실행·확인에 수십 초가 걸려 관객 앞에서 대기가 생긴다
- 해외에서 로그인·인증이 막히면 대안이 없다

**대신 이렇게 쓰는 것이 좋다**: 실행은 `START-DEMO.bat`으로 하고,
Claude Code는 **문제가 생겼을 때 진단·수정용 백업 수단**으로만 설치해 둔다.

## 8. 공개 터널 (Cloudflare Tunnel) — 네트워크 대비책

### 언제 쓰나

같은 Wi-Fi 방식(`START-DEMO.bat`)이 통하지 않는 상황의 우회로다.

| 상황 | 터널이 해결하는가 |
|---|---|
| 행사장 Wi-Fi가 기기 간 통신 차단(AP 격리) | ✅ |
| 태블릿이 LTE만 되고 노트북과 다른 망 | ✅ |
| 인증서 경고("연결이 비공개가 아닙니다")가 부담스러움 | ✅ 정식 인증서라 경고 없음 |
| 한국 원격 참관자에게 실시간 시연 | ✅ 주소만 전달 |
| 인터넷 자체가 없음 | ❌ 터널은 인터넷 필수 |

### 준비 (최초 1회)

```bash
winget install --id Cloudflare.cloudflared -e
```

### 실행

`START-TUNNEL.bat` 더블클릭 → 창 2개가 열린다.

- **AEPICK - Tunnel Address** 창: 5초쯤 뒤 `https://xxxx.trycloudflare.com` 표시
- **Demo Server** 창: 서버 로그 + **이번 실행용 관리자 키**

터미널 사용 시:

```bash
npm run demo:tunnel
```

(이 명령은 서버만 띄운다. 터널은 별도 창에서 `cloudflared tunnel --url http://localhost:8787`)

### 동작 방식

```
태블릿/휴대폰 ──HTTPS(정식 인증서)──▶ Cloudflare ──HTTP──▶ 노트북 :8787
```

- TLS를 Cloudflare가 종단 처리하므로 **로컬 서버는 HTTP로 뜬다**
  (`START-TUNNEL.bat`이 `HTTPS=` 를 비우고 `TUNNEL=1`을 설정)
- 태블릿 입장에서는 정식 HTTPS이므로 **카메라가 정상 동작**한다
- 서버가 `trustProxy`로 `X-Forwarded-Proto`를 신뢰해
  **QR 주소가 터널 도메인 + https로 자동 생성**된다

### 주의사항

- **주소는 켤 때마다 바뀐다.** 재시작하면 태블릿에 새 주소를 다시 입력
- **주소를 아는 사람은 누구나 접속 가능하다.** 시연 시간에만 열고 끝나면 창 2개를 모두 닫는다
- 참가자 사진이 인터넷을 경유한다. 동의 문구 범위 내에서만 운용
- `TUNNEL=1`이면 관리자 키가 **매 실행 무작위 생성**된다 (기본값 `aepick-admin`은 차단).
  키는 서버 창 `ADMIN` 줄에 표시된다
- 사내망에서는 **보안 정책을 먼저 확인**한다. 터널은 보안팀 관점에서
  "방화벽을 우회해 내부 PC를 외부에 노출하는 행위"로 분류될 수 있다
- 무료 `trycloudflare.com`은 SLA가 없다. **주력이 아니라 대비책으로** 둔다
