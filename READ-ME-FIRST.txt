========================================================
 AEPICK BEAUTY DNA  -  시연 노트북 설치 안내
========================================================

[ 1단계 ] Node.js 설치  (최초 1회, 인터넷 필요)
--------------------------------------------------------
  https://nodejs.org  접속 -> LTS 버전 다운로드 -> 설치
  * 반드시 22 버전 이상이어야 합니다.
  * 이미 설치돼 있으면 건너뛰세요.


[ 2단계 ] 이 폴더를 원하는 위치에 두기
--------------------------------------------------------
  압축을 푼 폴더를 아무 곳에나 두면 됩니다.
  (예: 바탕화면 또는 C:\AEPICK)

  ※ Dropbox / OneDrive 폴더 안은 피하세요.
    동기화가 파일을 잠가서 실행이 실패할 수 있습니다.


[ 3단계 ] 실행
--------------------------------------------------------
  START-DEMO.bat  파일을 더블클릭

  - 처음 실행하면 필요한 패키지를 자동 설치합니다.
    (인터넷 필요, 3~5분 소요. 이때 한 번만 걸립니다)
  - 이후에는 10초 내에 바로 켜집니다.


[ 4단계 ] 태블릿 연결
--------------------------------------------------------
  검은 창에 아래처럼 주소가 나옵니다.

     KIOSK  (TABLET)    https://192.168.x.x:8787/   <-- open on tablet

  1) 노트북과 태블릿을 같은 Wi-Fi 에 연결
  2) 태블릿 브라우저에 위 주소 입력
  3) "연결이 비공개가 아닙니다" 경고가 나오면
     [고급] -> [계속] 을 한 번만 누르세요  (정상입니다)
  4) 카메라 권한 요청 -> 허용

  * 노트북에서만 볼 때는  https://localhost:8787/


[ 4-B단계 ] Wi-Fi 가 막혔을 때 - 공개 터널 (선택)
--------------------------------------------------------
  아래 상황이면 START-DEMO.bat 대신 START-TUNNEL.bat 을 쓰세요.

    * 행사장 Wi-Fi 가 기기끼리 통신을 막아 태블릿 접속이 안 됨
      (게스트 Wi-Fi / AP 격리 환경에서 흔함)
    * 태블릿이 LTE 만 되고 노트북과 같은 망에 못 붙음
    * 한국에 있는 사람에게 실시간으로 보여줘야 함

  준비 (최초 1회, 인터넷 필요):
    PowerShell 을 열고 아래 한 줄을 실행

      winget install --id Cloudflare.cloudflared -e

  실행:
    START-TUNNEL.bat  더블클릭
    -> 창이 2개 열립니다.
       "AEPICK - Tunnel Address" 창에 5초쯤 뒤 주소가 뜹니다.

         https://xxxx-xxxx-xxxx.trycloudflare.com

    이 주소를 태블릿에 입력하세요.

  터널을 쓰면 좋은 점:
    * 인증서 경고가 없습니다 (정식 HTTPS)
    * 같은 Wi-Fi 가 아니어도 됩니다. LTE 로도 열립니다
    * QR 도 이 주소로 만들어져서 어느 폰에서나 열립니다

  주의:
    * 인터넷이 반드시 필요합니다 (오프라인 불가)
    * 주소는 켤 때마다 바뀝니다. 재시작하면 새 주소를 다시 입력
    * 이 주소를 아는 사람은 누구나 접속할 수 있습니다.
      시연 시간에만 켜고, 끝나면 창 2개를 모두 닫으세요.
    * 관리자 대시보드 키는 실행할 때마다 무작위로 만들어집니다.
      검은 창의 ADMIN 줄에 표시되니 필요하면 적어두세요.
    * 사내망에서 켤 때는 보안 정책을 먼저 확인하세요.
      터널은 "방화벽을 우회해 내부 PC를 외부에 노출하는 행위"로
      분류될 수 있습니다.


[ 5단계 ] 대기화면 통계 채우기 (선택)
--------------------------------------------------------
  SEED-DATA.bat  더블클릭 -> 1 입력 -> Enter
  (참여자 수 / 인기 DNA 가 화면에 표시됩니다)


[ 종료 ]
--------------------------------------------------------
  검은 창에서 Ctrl + C  또는 창 닫기
  * 시연 중에는 창을 닫지 마세요. 서버가 함께 꺼집니다.


[ 자주 겪는 문제 ]
--------------------------------------------------------
  * 태블릿에서 카메라가 안 켜짐
    -> 주소가 https:// 로 시작하는지 확인

  * 태블릿에서 접속이 안 됨
    -> 같은 Wi-Fi 인지 확인
    -> Windows 방화벽에서 Node.js 허용 여부 확인
    -> 그래도 안 되면 4-B단계(START-TUNNEL.bat)로 우회

  * Wi-Fi 를 바꿨더니 접속이 안 됨
    -> 서버를 껐다 켜고, 새로 표시된 주소를 다시 입력

  * AI 이미지가 안 나옴
    -> 자동으로 기본 이미지가 생성됩니다. 정상 동작입니다.


[ AI 이미지 생성을 켜려면 ]
--------------------------------------------------------
  START-DEMO.bat 을 메모장으로 열고 아래 두 줄에서
  REM 을 지운 뒤 키를 붙여넣으세요.

     REM set AI_PROVIDER=gemini
     REM set GEMINI_API_KEY=PASTE_YOUR_KEY_HERE

  키가 없거나 오류가 나도 체험은 정상 진행됩니다.
